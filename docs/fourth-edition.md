## 跨版本兼容处理

2026-10-21 合入 fallen 后续 10 个提交，加入“一起听”角色点评、自主切歌、播放操作上下文同步及弹幕布局优化。保留整合版聊天发送后自动触发回复的修复。

1. 多会话的新建、继续和列表查询都保留聊天账户；嵌入剧情的窗口使用当前会话的账户，而非切换后的全局账户。
2. 自动去重与手动重复会话提示均跳过用户主动创建的独立线程；主号和小号之间不重定向历史消息。
3. 联系人入口返回对应账户的基础会话，避免误选命名的新窗口。
4. 主题资产批量读取保留 URL/data/blob 直通，同时使用单次数据库读取。
5. 文档发送也通知剧情嵌入聊天的消息回调。
6. 合并两边的 CSS 前统一行尾，再按原作者基线三方合并，保留两边新增规则。

## 本地运行与检查

使用 Node.js 22 或更新的受支持 LTS 版本：

```bash
npm ci
cp .env.example .env.local
npm run dev
npm run typecheck
npm run check:integration
npm run check:sdk
npm run check:weixin
npm run check:push
npm run build
```

`check:integration` 使用真实源码函数检查账户隔离、独立线程保留、基础会话选择和主题资产批量读取，不调用 AI 接口。

## Netlify

仓库根目录直接导入 Netlify：构建命令 `npm run build`，发布目录 `.next`。`netlify.toml` 配置 Node.js 22 和 `NEXT_PUBLIC_SELF_HOSTED_MODE=true`，使用个人单机模式。

LLM、生图、语音等 API 仍由使用者在应用设置里填写。Supabase、微信助手、离线推送和特调云端按原有文档独立配置；未配置外部服务不代表本地整合失败。

更新已有 Netlify 站点时，优先在原站点切换关联仓库，以保留域名、环境变量和浏览器数据所属域。更新前在旧版「设置 → 数据管理」导出完整备份。新域名不会自动取得旧域名的浏览器本地数据。
